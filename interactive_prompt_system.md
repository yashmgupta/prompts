# INTERACTIVE DIAGRAM GENERATOR PROMPT

I want you to generate interactive, dynamic flowchart applications using a fixed, reusable HTML/JS architecture.
There are TWO separate design layers:
1. **Interactive Data State** — changes for every diagram based on user requirements.
2. **HTML/JS Application Shell** — NEVER changes its core logic and styling.

The HTML interface, layout, spacing, toolbar, rendering engine, and CSS must remain consistent every time. Only the initial state (nodes and edges) changes.

## WORKFLOW

### Stage 1 — Architecture & State Design
Do not hardcode SVG elements. You must design a JavaScript **State Object** that represents the flowchart.
*   Define an array of `nodes`: `{ id, x, y, width, height, text, type, rotation }`
*   Define an array of `edges`: `{ from: id, to: id, type }`
*   Automatically calculate optimal initial `x` and `y` positions for the requested diagram.

### Stage 2 — Interactivity Requirements
The generated application MUST include the following dynamic capabilities:
*   **Moveable:** Users can click and drag any node to freely reposition it.
*   **Editable:** Users can double-click a node's text to edit it in place.
*   **Dynamic:** Users can click an "Add Node" button in the toolbar to spawn a new shape.
*   **Orientation Changes:** A toolbar button must toggle the entire diagram's layout between `Vertical Flow` (Top-to-Bottom) and `Horizontal Flow` (Left-to-Right), recalculating `x` and `y` smoothly.

### Stage 3 — Build the Application
Construct the diagram using Vanilla JavaScript and an SVG canvas.
Use:
*   `foreignObject` inside SVG for `contenteditable` text editing.
*   `<rect>` or `<path>` for node backgrounds.
*   `<path>` with SVG markers for connectors.
*   A centralized `render()` function that clears and redraws the SVG based on the JS State.

**Never:**
*   Use canvas (`<canvas>`) for the diagram (stick to DOM/SVG for editability).
*   Hardcode standard SVG nodes in the HTML (they must be generated by JS).
*   Use `alert()` or `prompt()`.

## FIXED VISUAL SYSTEM
Maintain this minimal, editorial aesthetic:
*   Background: `#f4f4f2`
*   Nodes: White fill, `#242424` stroke, 1.7px stroke-width, subtle 5px border radius.
*   Connectors: `#242424`, 1.7px stroke, square linecaps.
*   Typography: Garamond, "EB Garamond", Georgia, serif.
*   Provide generous whitespace and balanced spacing.

## INTERACTIVE BEHAVIORS TO IMPLEMENT
1.  **Drag and Drop:** Attach `mousedown`, `mousemove`, and `mouseup` to the SVG window to track active node dragging. Update state `x` and `y` and call `render()`.
2.  **Editable Text:** Use `<foreignObject>` mapped to the node's dimensions. Contain a `<div contenteditable="true">`. Add a `blur` event listener to save text back to state.
3.  **Auto-Layout:** Provide a `recalculateLayout(direction)` function that loops through nodes and assigns new mathematical x/y values based on spacing constraints, then calls `render()`.
